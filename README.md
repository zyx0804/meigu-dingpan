# 美股盯盘（网页版）

在自己电脑上运行、用浏览器打开的美股盯盘工具：行情、每日自动选股、持仓风险评估、动态止损、一键挂保护单、按规则买入、交易复盘与规则进化。连接的是你自己电脑上的 moomoo OpenD，账户和密码不会离开你的电脑。

## 安装（第一次）
1. 安装 Python 3.10 或更新版本：<https://www.python.org/downloads/>（安装时勾选 **Add python.exe to PATH**）
2. 在 [Releases](../../releases/latest) 页面下载最新版的 **Source code (zip)**，解压到任意位置
3. 双击 `install.bat` 安装依赖
4. 双击 `start-web.bat`，浏览器会打开 <http://127.0.0.1:8765>

只看行情和选股，到这里就能用了。

## 连接 moomoo（看持仓、挂单、买入时需要）
1. 下载 moomoo OpenD：<https://www.moomoo.com/download/OpenAPI>（Windows 版）
2. 打开 OpenD，用**你自己的** moomoo 账号登录，端口保持默认 11111
3. 刷新网页，「持仓 · 风险」页会显示你的账户
4. 挂单或买入前，在 OpenD 窗口里点「解锁交易」并输入交易密码（密码只输进 OpenD，本程序碰不到）

## 自动更新
程序每 6 小时（以及启动后约 20 秒）检查这里有没有新版本，有就自动下载、替换程序文件并重启。
- 每个版本都带发布者的数字签名，签名或任何一个文件的校验值对不上就拒绝安装（即使 GitHub 账号被盗也装不上假版本）
- 自动安装只在美股常规交易时段之外进行，盘中不会重启打断止损规则
- 你的 `stocks.json` 和 `data` 文件夹不会被改动；旧文件会备份到 `backup/` 里
不想自动更新：把 `update.json` 里的 `"auto": true` 改成 `false`，网页顶部会改为提示你手动更新。

## 安全说明
- 网页只监听本机 127.0.0.1，局域网和外网都连不上；每次启动生成随机令牌，别的网站无法操作
- 下单类操作都需要你在网页上确认；程序会在服务器端重新按规则计算价格和股数
- 平仓单只会平掉已有持仓；买入必须通过买入规则（趋势、风险预算、仓位上限、购买力）
- 选股、风险评估、止损参数都是按历史数据和固定规则算出来的，**不是投资建议**；买卖和风险由你自己决定

完整功能说明见 `美股盯盘说明.md`。
